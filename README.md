# show-once

화면 녹화 한 번을 부모님이 혼자 따라 할 수 있는 단계별 가이드로 바꾸는 영상 분석 파이프라인

> 서비스 가칭: **미정** · 상태: 설계 완료, 개발 시작 전

## 무엇을 하나

1. 자녀가 안드로이드 폰에서 작업을 한 번 하며 화면을 녹화한다 ("화면 터치 표시" 켬).
2. 녹화를 올리면 **행동 단계** 단위로 나뉜 가이드가 만들어진다. 단계마다 화면 이미지, 누를 곳, 쉬운 설명이 붙고 개인정보는 자동으로 가려진다.
3. 부모님은 링크로 가이드를 열어 한 단계씩 따라 한다.

## 최종 목표

가이드를 바탕으로, 부모님이 실제 폰을 쓰는 동안 화면 위에 **다음에 누를 곳을 실시간으로 짚어주고**, 부모님이 누르면 반응해서 다음 단계로 넘어가는 **실시간 안내 모드**(안드로이드 앱)를 만든다. 원격 제어 없이 부모님이 직접 누른다.

- 녹화에서 찾은 "누른 곳"을 부모님 화면의 실제 버튼과 연결하는 것이 핵심 문제다. 글자 크기, 기종, 앱 버전이 달라도 같은 버튼을 찾아야 한다.
- 웹 가이드는 계속 유지한다. 앱 없이 가이드 형식을 먼저 검증하는 수단이고, 아이폰이나 앱 설치가 어려운 경우의 대안이다.
- 부모님 화면 정보는 기기 안에서만 처리하고 서버로 보내지 않는다.

## 처리 흐름

```
녹화 영상 → S0 프레임 추출 → S1 화면 전환 후보 ┐
                          → S2 터치 검출      ┴→ S3 행동 단계 조립
        → S4 OCR → S5 개인정보 가림 → S6 설명·묶음 생성 → 가이드
```
